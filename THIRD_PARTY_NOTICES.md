The project tree uses Material Icon Theme v5.39.0. Its assets and MIT license are included under `assets/material-icon-theme/`; see `ATTRIBUTION.md`.

## rfd

## Sublemon language service

The local stdio JSON-RPC server and lexical language features are original Sublemon code. No third-party editor package format, grammar bundle, external language server, or editor plugin is included or executed.
